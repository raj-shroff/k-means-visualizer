# Café customer clustering

A classroom demo of k-means clustering for café customer analytics. Use fictional spending and visit data to see how customers form clusters. Change K, follow each calculation step, and select technical terms for definitions.

To use it online, open the GitHub Pages URL shown under this repository’s **Deployments → github-pages** after publication. To enable publication, select **Settings → Pages → GitHub Actions**, then run the **Deploy GitHub Pages** workflow.

To run it locally, clone or download this repository. With Node.js 22 or later installed, run `npm run preview` from the repository folder and open [localhost:8080](http://localhost:8080). No package installation is needed. Use `git pull` to get later updates and `npm test` to check the calculations.
